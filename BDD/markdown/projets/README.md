# Projects

Description de la section : *My most notable projects*

Chaque catégorie est affichée sous forme de carrousel de cartes. Un fichier = une carte.

➕ **Nouveau projet :** copie [_template.md](_template.md).
📊 Étoiles, forks et dates de secours : [`../../json/projects.json`](../../json/projects.json).

Les cartes qui ont un attribut `data-repo="owner/nom"` dans `index.html` sont complétées
automatiquement depuis GitHub : langages, stars, forks, date de mise à jour,
lien GitHub et lien du site (homepage ou GitHub Pages).
Les images sont des fichiers locaux dans `asset/picture/projects/` (aperçus GitHub téléchargés,
à remplacer par tes propres captures en gardant le même nom).
La description vient de GitHub (« About » du dépôt), sinon du texte écrit à la main, sinon du README.
